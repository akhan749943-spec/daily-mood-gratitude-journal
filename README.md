# Daily Mood & Gratitude Journal

A mindful, privacy-first **Daily Mood, Gratitude & Task Accomplished Journal** built as an installable Progressive Web App (PWA).

## Key Features
- **Daily Reflection & Mood Composer**: Log a 1–5 mood rating, custom influence tags, card highlight theme, and daily gratitude note.
- **Works & Tasks Accomplished (Power System)**: Independent daily routine checklist with inline task editing and manual check-off.
- **Separate Visual Trend Line Charts**: Interactive 7-day (Weekly) and 30-day (Monthly) SVG line charts for both Daily Mood and Task Accomplished trends.
- **Past Tasks / To-Do History Tab**: Filter accomplished tasks by exact calendar date, Last 7 Days, or Last 30 Days.
- **Dual-Key Safety Vault & 15-Day Trash Bin**: Automatic local backup protection plus 15-day recovery for deleted entries.

## Deployment
- Upload `index.html`, `manifest.json`, and `README.md` to a GitHub repository.
- Import the repository into Vercel for an instant `.vercel.app` live web link.
